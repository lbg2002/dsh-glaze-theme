# 瓷釉 · `dsh-glaze-theme`

[English](README.en.md) | 中文

专为 **DeepSeek Harness (`dsh`)** 打造的东方美学深度 UI 定制主题插件：**16 套中国风配色、6 套东方意境全案预设、0% 空载显卡/CPU 消耗**。

不仅支持调整表面色彩，还深度适配**左侧边栏基调、右侧对话区底色与静态国风底纹、思考过程展示卡片（含楷体手批）、输入框框体造型、发送按钮形状、用户气泡造型**，以及**软件名称（含字号/特效）、首页欢迎语、艺术字体与左下角个人栏**，所有设置自动持久化至 `~/.dsh/glaze-theme.json`。

---

## 核心特性

### 1. 极致低消耗（目标：静止时 0% CPU / 0% GPU）
* **默认「瓷釉零模糊」模式**：不开启昂贵的全页 `backdrop-filter: blur`，改用 OKLCH 通透色阶、顶部 1px 高光边与三层静态柔影，避免 Linux / XWayland / 核显环境显卡高占用。
* **零常驻动画循环**：无 CSS `@property` 呼吸循环、无 `infinite` 全屏动画、无 `setInterval` 轮询。
* **按需可选「轻雾静态毛玻璃」**：可在设置面板内一键切换仅作用于侧栏与输入卡的静态毛玻璃模式。

### 2. 6 套东方意境全案 + 16 套 WCAG AA 莫兰迪色板
点击顶栏按钮即可一键联动整套配色、侧栏、底纹、思考卡片、输入框造型与字体：
* **兰亭水墨**（沉檀深栏 · 宣纸素笺 · 墨卷朱批楷书）
* **千里江山**（分明书案 · 远山含黛 · 竹简经折）
* **敦煌飞天**（岩彩流金 · 祥云瑞霭 · 文武双线框）
* **紫禁丹宸**（朱漆深栏 · 宫格窗棂 · 朱印方章）
* **江南听竹**（烟雨苍竹 · 远山轮廓 · 水墨细框气泡）
* **宋韵汝窑**（天青铁足 · 冰裂开片 · 极简禅意）
* 另含天青、黛蓝、朱砂、桃夭、竹青、赭石、青金、琥珀、落霞、青莲共 16 套色板，全部通过 WCAG AA 对比度校验。

### 3. 深度 UI 组件定制
* **左侧边栏 & 右侧对话区**：支持「分明书案 / 沉檀深栏 / 通透一体 / 自定义侧栏色」以及右侧画布自定义底色与 5 种静态纹理（四隅流光、宣纸素笺、远山含黛、宋锦冰裂纹、祥云瑞霭）。
* **思考过程样式**：支持「墨卷朱批」「竹简经折」「极简禅意」「官方原生」，并可开启**思考过程楷体手批风**（自动按需加载霞鹜文楷），同步联动「深度求索中」状态颜色。
* **输入框 & 发送键 & 气泡**：4 种输入框框体（温润瓷砚、文人花笺四角线、文武双线、悬浮流云）、3 种发送键形状（圆融明珠、朱印方章、温玉圆方）与 3 种用户消息气泡造型。

### 4. 艺术字体库与全界面品牌定制
* 内置 **霞鹜文楷、马善政楷书、站酷小薇体、志莽行书、思源宋体、Cinzel、Space Grotesk、JetBrains Mono** 与自定义本机字体。
* 独立调节**左上角软件名称字号（12–28px）**与**首页欢迎语字号（20–42px）**及纯色/琉璃渐变/微光冷晕效果。
* 自定义左上角软件名/角标/Logo、首页欢迎语（固定/自定义/随配色古诗词/按早中晚时段问候）、输入框提示词及左下角个人昵称与头像（支持本地图片压缩上传）。

## 安装方法

```bash
dsh plugin --profile web add <仓库路径或 github:你的用户名/dsh-glaze-theme>
```
确认 `~/.dsh/profiles/web/package.json` 的 `dsh.profile.bundles` 包含 `"dsh-glaze-theme"`（或直接运行 `node scripts/install-local.mjs web`），随后重启 DeepSeek Harness 服务即可。
