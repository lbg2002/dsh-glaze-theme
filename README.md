# 瓷釉 · `dsh-glaze-theme`

[English](README.en.md) | 中文

专为 **DeepSeek Harness (`dsh`)** 打造的高颜值、**零空载显卡/CPU 消耗**主题与全界面品牌定制插件。

保留中国风莫兰迪瓷釉质感，同时允许在界面内自由定制**软件名称、徽章、Logo、首页欢迎语、艺术字体、发送按钮主题色、底部个人昵称与头像**，所有配置持久化保存于 `~/.dsh/glaze-theme.json`。

---

## 核心特性

### 1. 极致低消耗（目标：静止时 0% CPU / 0% GPU）
* **默认「瓷釉零模糊」模式**：不开启昂贵的全页 `backdrop-filter: blur`，改用 OKLCH 通透色阶、顶部 1px 高光边与三层静态柔和阴影塑造瓷器质感，避免 Linux / XWayland / 核显环境显卡高占用。
* **零常驻动画循环**：绝不使用 CSS `@property` 呼吸循环或 `infinite` 全屏渐变动画；仅保留鼠标悬停/点击时的 140ms 轻量过渡。
* **零轮询 / 零重型监听**：无 `setInterval` 脚本轮询，无全局文本节点扫描。
* **按需可选「轻雾静态毛玻璃」**：如果你硬件充裕，也可以在设置面板里一键开启仅作用于侧栏与输入卡的静态毛玻璃模式。

### 2. 10 套 WCAG AA 达标莫兰迪配色 + 自定义主色
内置 10 套明暗自适应中国风色板（天青、黛蓝、朱砂、桃夭、竹青、赭石、青金、琥珀、落霞、青莲），支持**自定义主强调色（同步作用于发送按钮、焦点框与高亮态）**。

### 3. 艺术字体库（按需加载）
支持为**软件名称**与**首页欢迎语**选用多款艺术/书法/极客字体（支持国内加速镜像 `fonts.loli.net` 或 Google Fonts，也可填本机字体）：
* 霞鹜文楷（温润书卷） / 马善政楷书（毛笔书法） / 站酷小薇体 / 志莽行书
* 思源宋体 / Cinzel 古典铭文 / Space Grotesk / JetBrains Mono
* 支持 **墨韵纯色 / 琉璃双色渐变 / 微光冷晕** 三种文字艺术样式及字号滑条。

### 4. 全界面可视化定制（无需修改源码）
点击右上角顶栏的 **「瓷釉」胶囊按钮 → 「✦ 品牌 / 字体 / 个性化设置」** 即可实时编辑：
* **左上角品牌栏**：自定义软件名、右侧胶囊角标（自定义或隐藏）、替换本地图片/Emoji/隐藏图标、修改窗口标题。
* **首页欢迎区与输入框**：自定义欢迎语（或**随配色古诗词自动切换** / **按早中晚自动问候**）、副标徽章、中央图标、隐藏点击跃起鲸鱼 Canvas、自定义输入框占位提示词。
* **左下角个人栏**：自定义本地展示昵称与头像（支持上传本地图片并自动压缩为轻量 WebP/PNG，不影响真实账号登录与菜单）。
* **配置备份**：支持一键导出 / 导入 JSON 及恢复默认，自动保存至 `~/.dsh/glaze-theme.json`。

## 安装方法

### 方式一：通过 `dsh plugin` 安装（推荐）
```bash
# 从本地目录或 GitHub 仓库安装
dsh plugin --profile web add <仓库路径或 github:你的用户名/dsh-glaze-theme>
```
确认 `~/.dsh/profiles/web/package.json` 的 `dsh.profile.bundles` 数组中包含 `"dsh-glaze-theme"`，然后重启 DeepSeek Harness 服务即可生效。

### 方式二：在源码目录一键本地构建并安装
```bash
npm run build
npm test
node scripts/install-local.mjs web
```
